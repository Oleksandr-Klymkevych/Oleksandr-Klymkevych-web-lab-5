# 1. Тестування методу GET (перший запит — X-Cache: MISS, повторний — X-Cache: HIT)
curl -D - -o /dev/null http://127.0.0.1:3000/200
curl -D - -o /dev/null http://127.0.0.1:3000/200

# 2. Запит неіснуючого коду стану на http.cat (очікується 404, у кеш не зберігається)
curl -i http://127.0.0.1:3000/999

# 3. Тестування методу PUT (завантаження картинки в кеш під кодом 418 — очікується 201)
curl -i -X PUT --data-binary @cache/200.jpg http://127.0.0.1:3000/418
curl -D - -o /dev/null http://127.0.0.1:3000/418

# 4. Перевірка валідації порожнього тіла PUT (очікується 400 Bad Request)
curl -i -X PUT http://127.0.0.1:3000/418

# 5. Тестування методу DELETE (перше видалення — 200, повторне — 404)
curl -i -X DELETE http://127.0.0.1:3000/418
curl -i -X DELETE http://127.0.0.1:3000/418

# 6. Перевірка недозволеного методу та некоректного шляху (очікується 405 і 404)

curl -i http://127.0.0.1:3000/invalid
